# 💻 PulseDesk — Portal de Atendimento de TI

> Aplicação web responsiva desenvolvida para centralizar, organizar e gerenciar a abertura e o acompanhamento de chamados de suporte corporativo, alinhada às boas práticas de Service Desk e conceitos inspirados na ITIL.

---

## 📌 Visão Geral

### Contexto
A equipe de Service Desk recebe solicitações de suporte por diferentes canais, o que dificulta a organização, a priorização e a rastreabilidade das demandas dos colaboradores.

O **PulseDesk** surge para resolver essa dor, funcionando como um portal único de atendimento de TI. Além da solução funcional, o projeto é utilizado para desenvolver e exercitar habilidades de desenvolvimento Front-end, organização de código, controle de versão com Git/GitHub, documentação e evolução incremental de software.

### Objetivo
Desenvolver uma aplicação web responsiva para registro e gerenciamento de chamados de TI, evoluindo progressivamente de uma interface estática para uma aplicação com regras de negócio, persistência de dados e futura integração com serviços em Cloud.

---

## 🎯 Escopo do Projeto

O **PulseDesk** deverá permitir a abertura, classificação, visualização e acompanhamento de chamados de TI.

> **Evolução Incremental:** O desenvolvimento será incremental. Funcionalidades mais avançadas — como priorização, SLA, persistência, indicadores e Cloud — serão adicionadas conforme a evolução das sprints.
